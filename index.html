Taskpad

How this works
state
One array of task objects (id, text, done, created). Every change updates the array, then calls render().
DOM
render() rebuilds the list with createElement and textContent, so typed text is never parsed as HTML.
events
The form's submit event covers both the Add button and the Enter key. One click listener on the list handles every checkbox and delete button (event delegation).
storage
save() writes the array to localStorage as JSON after each change. On load, JSON.parse reads it back, so tasks survive a reload.
